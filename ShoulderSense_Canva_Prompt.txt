Create a professional 12-slide, 16:9 presentation titled "ShoulderSense — Wearable Monitoring for Frozen Shoulder Rehabilitation."

Audience: faculty evaluators and engineering students. Design for an 8–10 minute academic demonstration.

Visual style: use a navy, teal, and white palette, clean typography, and generous spacing. Give each slide one main message. Prefer diagrams, charts, and annotated screenshots to paragraphs. Use editable placeholders for team details, hardware photos, real application screenshots, and any results that have not been supplied.

SLIDE OUTLINE

1. Title
Show the project name and placeholders for the team, institution, and supervisor. Add a simple illustration showing one sensor on the chest and one on the wrist.

2. The problem
Ask: How can we measure a patient's exercise performance and track changes across days and weeks?

3. System architecture
Use a left-to-right diagram: Chest and wrist BNO086 IMUs → ESP32 → FastAPI backend and session storage → React dashboard.

4. How movement is measured
Show neutral calibration, chest orientation as the torso reference, wrist movement relative to the chest, and estimated raise-and-return cycles. Illustrate one estimated repetition with a schematic angle-versus-time graph marking the start, peak, and return.

5. Live Monitoring
Add a screenshot placeholder. Highlight the animated arm, live angle estimate, estimated repetitions, and recording controls. Keep sensor diagnostics secondary.

6. Session measurements
Group the measurements into movement, consistency, torso motion, and symptoms. Include median rep excursion, estimated reps versus an optional prescribed target, rep duration and variation, wrist speed, jerk when supported, torso rotation, and optional pain and stiffness ratings. Distinguish coarse wrist jerk from the 50 Hz metric.

7. Personal baseline
Show how the first three comparable live sessions establish a baseline. Compare sessions for the same patient, exercise, shoulder side, and measurement setup. Add a Progress Analytics screenshot placeholder and show where actual changes in degrees, seconds, or rating points would appear.

8. Experimental performance index
Use a prominent 2×2 grid with these four components. Put the weight and the measured inputs inside each tile:

- Mobility — 40%: Median excursion across completed estimated reps, compared with the prescribed excursion target or the patient's own baseline.
- Movement Control — 25%: How consistently the patient repeats the movement. Use variation in peak angle and rep duration, plus wrist jerk when the signal supports it.
- Torso Control — 15%: Peak torso rotation measured by the chest IMU, compared with the patient's own baseline. Label this as a posture estimate.
- Pain and Stiffness — 20%: Optional patient-reported ratings on separate 0–10 scales. Show these as self-reported symptoms.

Add one line under the grid: "An experimental index of recorded exercise performance. Missing measurements can result in a labelled partial score."

9. SPARS9x Dataset Replay
Show how recorded wrist motion can be replayed independently of ESP32 hardware. Mention 20 participants, 10 exercise labels, and 3,839 analyzed wrist-data windows. Present wrist measurement ranges as dataset context and keep them separate from the patient's own progress.

10. Demo walkthrough
Show the sequence: select a mode and exercise → set neutral for Live ESP32 → record → finish and save → open Progress Analytics. Include Dataset Replay as the hardware-free demo path.

11. Verification and limitations
Report 64 passing backend tests, a successful frontend production build, and desktop and mobile browser checks. Distinguish software verification from physical validation. Explain that physical angle accuracy still needs an independent reference measurement and that sparse sampling limits jerk detail.

12. Conclusion and Q&A
Close with: "ShoulderSense turns wearable readings into comparable rehabilitation sessions." List three next steps: independently verify angles, compare estimated reps with observer counts, and collect comparable sessions over several weeks.

Add one or two short speaker notes per slide if supported. Use placeholders for real screenshots, graphs, and patient results. Present ShoulderSense as an academic rehabilitation monitoring prototype. Give the experimental performance index no clinical recovery interpretation.
